# Dashboard Surface Brief

- **Mode:** Persuade landing page and Operate logged-in home.
- **Audience and job:** Developers and product managers equally; understand recent flag changes, inspect rollout context, and edit or create flags.
- **Primary action:** Start now on the landing page; New flag and Edit flag in the logged-in workspace.
- **Chosen direction:** Activity Command Center with a persistent left sidebar, recent changes as the primary home content, and rollout context in a secondary rail.
- **Scope:** Landing page plus happy-path logged-in dashboard. Loading, error, empty, and permission states are intentionally out of scope.
- **Memorable moment:** Selecting a recent flag change reveals its current rollout state and makes the next action obvious.
- **Constraints:** Web, responsive, keyboard-focusable controls, product copy must remain clear and factual; use synthetic demo data until real data is available.
